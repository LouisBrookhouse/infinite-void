# Splitter

## Intent
Roadmap R0X. One gated enemy. A pyramid ship from the current wave 27 splits into 3 fast darts aimed at the ship. A fresh save stays on scouts. Not a meta threat. This branch does not open a PR.

## Scope
In scope: `splitter` and `dart` in `src/content/enemies.js`, `toast` on the content API, changelog 1.5.0, DESIGN, STATUS, ROADMAP, this note.
Out of scope: new guns, bosses, upgrades, meta threats, guardrail edits, and a pull request.

## Changes
- Review, same version. The 13×7 mirrored wedge read as a flat fighter. `splitter` is now a 15×14 unmirrored pyramid (fighter is 11×9). Three facets, black rim, orange seams. `IV.art.litUL` and `IV.art.tone` shade a metal ramp: lit left face in the sector colour, mid steel center, darker navy right, white speck on the upper left. `noBob`. Unlock wave 27, weight 0.35, hp 1.5, rew 1.45, spd 28, fire 0.35, shots 1, dmg 0.65. The first spawn in a page load toasts `NEW THREAT: SPLITTERS`. No `threat` field.
- Every non-boss wave from 27 spawns one splitter in `startWave` and consumes one `toSpawn`. Boss waves and a zero quota do not. Weight 0.35 can add a second.
- `onDeath` prints SPLIT and spawns 3 `dart`s on the wreck. For 0.34s each dart draws its facet and the facets fly apart, seams white. Then the facet is an arrowhead aimed along that flight: navy outline, yellow core, orange body, orange trail, no sector colour. It rotates by plotting pixels, not by rotating the canvas. `dart` is weight 0, `counts` false, hp 0.32, rew 0.18, ram 0.22×`eDmg`, a 9×9 empty sprite. It steers only while it is above the ship, then flies straight. Offscreen or 3.2s despawns with no pay. A second kill does not split. If the splitter is the last kill, `shardHold` waits out the 0.34s before `waveClear`.
- `A.toast` is the engine toast. No new save fields.
- First numbers (weight 1.4, darts that kept turning) let them circle and held the lane empty. min30 on-screen fell to 11.667, under the floor of 12. The first review pass guaranteed a splitter at ram 0.4 and killed the 30 minute run at minute 14 (warps became 2, so the warp check failed, and the post-death window emptied the screen). Shipped tune is one per wave, weight 0.35, pyramid hp 1.5, dart ram 0.22.
