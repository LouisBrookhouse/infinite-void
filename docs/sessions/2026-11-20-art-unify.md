# Same hand

## Intent
Louis asked for one art pass on 1.4.2: every newer sprite should match the original enemies, the player ship, and the dithered Verdant nebula. The same branch also had to restore Big Core and Xeno Biomech to their pre-1.2.3 shield and plate behaviour, keep the wave-125 health cap, and confirm both bosses still die before the 35s escape on the Louis save. The layout restore is blocked by the latescale suite. This note records that, and the paint that did ship. Not a roadmap item. R0X stays next.

## Scope
In scope: paint only, plus the art style guide and the blocked-revert note. Out of scope: hitboxes, attacks, shield offsets, plate HP, regrow timers, the health cap, `tests/`, and a pull request.

## Changes
`src/content/art.js` holds the master palette, the 4×4 Bayer function the nebula already used, the ramps, and helpers for plates, pods, spores, and discs. `index.html` loads it right after `core.js`. `src/game.js` reads `IV.art.PAL` and `IV.art.bayer` so planet and nebula pixels stay the same function.

Redrawn, same sizes: Mine Layer hull, mine, miner lamp-off color, Option Pods (in game and the shop icon), spore shots, Big Core shield paint, Xeno plate paint, the shield-break spark (`#7fe7ff`), THE MAW body, wall, tentacles, tips, eyes, mouth, stumps, part bars, and the eye laser. Left as they were: v1.0 enemies, Vanguard, the Eidolon shape, the escort drone (pods copy it), the original boss bodies, the original shots other than spore, and the rock.

Louis asked to put back the classic Big Core stack and the invulnerable swaying Xeno plates from before PR #11 (`69152cb`, parent `3cde506`; `955521f` is not in this repo), including the aim special-case, and to keep `HP_CAP_WAVE` 125, the bend at 100, `HP_LATE_MULT` 3.5, and `DMG_LATE` 1.12. That restore would fail these assertions in `tests/run.js`, so it was not made:

- line 699, `Big Core aim sits on the weak column`
- line 700, `Big Core aim is a gap, not a shield` (`covered === 0`)
- line 701, `Xeno aim sits on the plate that covers the core` (`covered >= 1`)
- lines 702-703, a wall and a center plate set to `hp = 0`, `down = 0.05`, then updated 0.1s, must read `hp === max` and `down === 0`

The old stacked walls cover the aim column. The old plates do not regrow and have no `maxHp`. `tests/` was not edited. Shield and plate numbers stay at 1.2.3. The cap is still the balance tool. DESIGN.md states that.

Balance before this paint (1.4.1): min5 wave 21 / onScreen 11.133 / TTK 1.197s, min15 wave 34 / 17.9 / 1.462s, min30 wave 44 / 14.533 / 2.939s, idle best 10, warp +13 Dark Matter. After: the same line. No numeric tweak.

The Louis save still kills both bosses before the 35s escape, on the 1.2.3 layout that the suite requires. Live Big Core at wave 120 dies in 10.93s. Live Xeno Biomech at wave 125 dies in 9.37s. Isolated at wave 125, Big Core dies in 7.2s and Xeno Biomech in 6.3s. No HP numbers were retuned.
