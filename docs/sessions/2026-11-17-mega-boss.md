# Mega boss

## Intent
Louis asked to drop the auto warp on THE MAW, stop calling it a final boss, and add boss tiers so later days are not biased toward an ending.

## Scope
In scope: clear flow in `src/game.js`, `tier` on every boss, HUD and warp copy, `?mega=1`, changelog 1.1.4, DESIGN, STATUS, ROADMAP, AGENTS.md, a mega suite, this note.
Out of scope: new elite bosses, new sectors, combat-number changes, and opening the pull request.

## Changes
- Clearing phase 5 plays `MAW FALLS`, grants Eidolon once, pays a bounty once per run, then `waveClear` continues (wave 96 with auto-advance). It does not Warp Jump.
- The bounty is `max(15, floor(dmGain() × 0.5))` Dark Matter plus `floor(eRew(wave) × 20)` credits. `S.megaPaid` blocks a second payout in the same run, including farm mode. Warp Jump and a hull breach clear `megaPaid`. A death still pays only `dmGain()`.
- `S.finalKills` stays the lifetime mega-boss clear count so old saves load. The stats row reads "Mega bosses slain".
- Registry `tier`: the five rotating bosses are `standard`, THE MAW is `mega` with `fromWave:91` and `phases:5`. Elite is documented and unused. The rotation skips anything that is not standard.
- HUD and toasts say `MEGA BOSS - PHASE n/5`. `?mega=1` jumps to wave 91 with `noSave`. `?final=1` still does that jump.
- No combat numbers changed. The 1.1.3 sim is the before measurement.

## Validation
- `npm test`: passed. Docs validator, 8 unit tests, smoke, save, migration, gating, balance, death, and the new mega suite.
- Balance, unchanged from 1.1.3 because no combat numbers moved: min5 wave 21 (10.8 on screen, TTK 1.099s), min15 wave 34 (15.633, 1.817s), min30 wave 44 (21.367, 3.619s), warp +13 DM, idle best wave 7.
- Mega suite: every boss has a tier, the rotation never returns the Maw, waves 91-95 are the mega span and 96 is not. Clearing phase 5 pays the bounty once, grants Eidolon once, leaves warps unchanged, writes the save, then continues at wave 96. A second clear in the same run adds no Dark Matter. A death after that pays `dmGain()` only and clears `megaPaid`. `?mega=1` and `?final=1` both open wave 91 without saving. `?mega=1&kit=1` still raises `debugMul`.
- Headless Chromium at `?mega=1&mute=1`: the HUD reads `MEGA BOSS - PHASE 1/5` and the banner reads `MEGA BOSS`. After the phase-5 kill the toast was `EIDOLON UNLOCKED +30 DM +¢16.1M`, warps stayed 0, and the next banner was `WAVE 96`. Console errors: none.
